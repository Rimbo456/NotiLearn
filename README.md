# About NotiLearn

NotiLearn is a smart micro-learning assistant designed for busy people who want to acquire new vocabulary effortlessly. By turning the Android notification bar and lock screen into interactive learning spaces, the app leverages the psychological trigger of checking your phone to foster passive, consistent learning.

Powered by Kotlin Multiplatform (KMP) and Clean Architecture, NotiLearn utilizes an intelligent Spaced Repetition System (SRS) to schedule reviews, while integrating Gemini Flash API to dynamically generate contextual examples, translations, and phonetic guides.
